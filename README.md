# Naozumi Tanabe — 個人ホームページ試作

GoogleサイトのProfile / Research / CVをもとにした、GitHub Pages用の静的サイトです。公開前に日本語訳、正式な科目名、氏名表記をご確認ください。氏名・指導教員名は漢字表記を推測せず元のローマ字表記を使っています。外部リンクは元サイトのものを引き継いでいます（リンク先の内容・共有権限は未確認）。

## 更新

`content.js` の `en` と `ja` に英語・日本語の各ページがあります。`String.raw` のバッククォート内に文章・HTMLとTeXを書きます。バックスラッシュは1つのままで使えます。

- 文中数式：`$E=mc^2$` または `\(E=mc^2\)`
- 独立数式：`$$\int_0^1 x^2\,dx = \frac13$$`
- 複数行：`$$\begin{aligned}a&=b+c\\d&=e+f\end{aligned}$$`

MathJax 4をCDNから読み込みます。数式の表示にはインターネット接続が必要です。LaTeX文書全体や全パッケージに対応するものではありません。HTMLの `<` は `&lt;`、`&` は `&amp;` と書いてください。バッククォートと `${` はJavaScriptの特殊記号なので、文章中で使うときは注意してください。`pre` / `code` 内の数式は処理しません。

## 言語

右上の EN / 日本語で切り替え、選択をブラウザに保存します。`?lang=ja#research` のように言語とページを指定したURLも利用できます。初回は英語です。

## GitHub Pagesでの公開

1. GitHubでサイト用リポジトリを用意します。
2. このフォルダのファイルをルートに配置します（README自体は公開サイトには表示されません）。
3. Settings → Pages → Deploy from a branchで `main`、`/ (root)` を指定します。
4. GitHubが発行するURLで表示を確認します。

この試作はGitHubへのアップロード・公開をまだ行っていません。サーバー処理やビルドは不要です。ローカル確認にはこのフォルダで `python3 -m http.server 8000` を実行して `http://localhost:8000` を開きます。
